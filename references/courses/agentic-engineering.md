# ⑤ 从 Vibe Coding 到 Agentic Engineering

状态：beta

## 唯一承诺

带一个已经能跑但不敢改的项目入场，为它补上规格、测试、机器门禁、独立 Review 和上线观察。

## 教学节点

1. 项目工程体检：行为、结构、风险和未知项；
2. 什么是正确、简单、可测试、可修改、可运维的代码；
3. 涉及持久化、多进程或多端时，读取 `../lessons/shared/database-and-data-authority.md`，画出数据权威源与访问链路；
4. 从验收标准生成测试矩阵；
5. 写一个修复前因正确原因失败、修复后通过的回归测试；
6. 小切片、小 diff、验证、commit 的 Agent Loop；
7. 适配项目的一条 `verify` 和 CI；
8. 独立 Review、上线观察和经验回流。

## 铁律与证据

测试数量和覆盖率不是目标。关键行为、历史 Bug 和高风险路径必须由成本合适的证据守住。涉及数据库时还需要一张进程/数据流图、明确的逻辑权威源和跨入口真实读写证据。完成需要 RED/GREEN 记录、真实 verify 与 CI、用户路径行为证据、独立 Review 和剩余风险。本课程正在拆分独立 lesson。
