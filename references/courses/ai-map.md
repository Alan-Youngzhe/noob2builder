# ① AI 世界地图：模型、Agent、Token 与 Skill

状态：beta

## 唯一承诺

拆开学生正在使用的 Claude Code 或其它 Agent，分清厂商、模型、API、应用、Agent、Token、Context、Memory、Tool、MCP、Skill、Plugin 与 Subagent。

## 教学节点

1. 厂商、模型、模型服务、应用和 Agent 五层；
2. Token、费用与 Context Window；
3. Context 与长期 Memory；
4. Agent、Tool 和执行循环；
5. Function Calling、MCP、Skill、Plugin 与规则文件；
6. 按能力、成本、速度、Context、工具和可用性做选型。

## 最小实验

围绕学生当前配置画 `MY_AI_MAP.md`，执行一次真实模型请求和一次临时文件读写。文件不得包含 API Key。

## 完成证据

学生能解释模型与 Agent、token 与 context、context 与 memory、Skill 与 Tool/MCP 的区别。本课程正在拆分独立 lesson。
