# ⑦ AI 产品 Sense：从模型能力到用户智慧

状态：beta

## 核心命题

只有模型，是智能；模型加上与当前任务相关、经授权、可追溯、可更新和删除的 Context，才可能形成产品中的智慧。

## 唯一承诺

学生能从用户问题、替代方案、Context、行动、反馈、信任、成本和模型升级后的生命力，判断一个 AI 产品是否值得做。

## 教学节点

1. 为什么空白聊天框和 API Wrapper 通常不是完整产品；
2. 画 Context Map：来源、更新、权限、时效、噪声和删除；
3. 从 Context 到 Action，再到 Feedback；
4. 用创业者视角检查用户、价值、分发、留存和成本；
5. 为真实用户结果设计 Eval，而不是只评语言流畅度。

## 最小实验与证据

拆解一个真实 AI 产品，把一个聊天框原型改成有 Context 获取、行动、反馈和失败恢复的产品流程；输出 Context Map 和一组结果 Eval。本课程正在拆分独立 lesson。
