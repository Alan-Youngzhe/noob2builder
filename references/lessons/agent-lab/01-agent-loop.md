# 拆开 Agent Loop

## 目标

学生能看懂 Agent 如何在用户、模型和外部环境之间循环，不把模型本身当作会操作电脑的程序。

## 讲授

模型接收 Context 并生成下一段内容；Agent Runtime 负责组织消息、提供工具描述、执行工具、把观察结果放回 Context，再决定是否继续。经典 ReAct 可以简化为：理解当前状态 → 选择动作 → 执行动作 → 观察结果 → 更新状态 → 回答或继续。

Function Calling 是模型提出结构化动作的一种接口；真正的文件读写、搜索和脚本执行由宿主程序完成。MCP 让外部工具以较统一方式被 Agent 发现和调用，但它不是 Agent 的全部运行逻辑。

## 实验

让当前 Agent 完成一个透明任务：在临时目录读取两个文本文件、比较内容、生成摘要文件并读回。每一步让导师指出：模型判断、工具请求、宿主执行、工具结果和下一轮 Context 分别是什么。

输出 `AGENT_LOOP.md`：

```text
用户目标 → Context → 模型决定 → 工具调用 → 环境结果 → 新 Context → 完成判断
```

## 证据

真实工具调用记录、生成文件和学生自己的流程解释。纯聊天演示不算工具实验。
