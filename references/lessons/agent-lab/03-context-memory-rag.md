# Context、Memory 与资料

## 目标

让 Agent 获得完成任务所需的高信号信息，同时避免把所有资料无边界塞入 Prompt。

## 讲授

Context 是当前请求能够看到的信息；Memory 是跨请求保存并在适当时重新取回的信息；RAG 是先检索相关资料，再把命中的片段放进 Context。KV Cache 和 Prompt Cache 是计算或请求复用机制，不等于用户长期记忆。

更好的 Agent 不只是“Prompt 更长”，而是知道：缺什么信息、去哪里找、来源是否可信、何时过期、谁有权限、怎样删除。

## 实验

准备三份短资料，其中两份相关、一份相似但错误或过期。让 Agent 分别在以下条件完成同一任务：

1. 没有资料；
2. 全部资料直接塞入；
3. 先检索再使用，并标明来源。

比较正确性、引用、Context 长度和错误信息干扰。输出一张 Context Map：来源、用途、更新、权限、时效、失败降级。

## 证据

三组结果对比、Context Map 和一条删除/过期策略。不得使用未经授权的真实客户资料。
