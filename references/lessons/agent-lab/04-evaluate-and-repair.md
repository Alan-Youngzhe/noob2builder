# Eval：故意让 Agent 失败

## 目标

把“感觉挺聪明”改成一组可重复任务和明确评分。

## 讲授

Agent Eval 先从真实任务失败开始，不必一上来使用复杂平台。测试集至少覆盖：正常任务、缺 Context、工具失败、相似干扰、越权请求和无法完成时是否诚实降级。

评分可以包含：最终结果、是否选对工具、参数是否正确、来源是否可靠、是否泄漏秘密、失败是否可恢复、成本与步骤。不要只评最后一句话是否流畅。

## 实验

1. 为当前 Agent 写五条固定任务和期望行为。
2. 先运行基线，保存原始结果，不先提示它“正确答案”。
3. 找到一个真实失败，判断属于模型能力、Context、工具定义、运行环境还是完成标准。
4. 只修改一个最可能原因。
5. 重跑五条任务，确认目标问题改善且其它任务没有明显回归。

## 证据

任务集、基线结果、失败分类、单项修改和复测结果。五条全靠人工主观打分时要标注局限；能写成断言的关键行为应自动化。
