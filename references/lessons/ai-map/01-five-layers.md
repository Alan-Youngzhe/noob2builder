# 谁做的、叫什么、你用的是哪一层

## 目标

学生能说出主流厂商各自做什么模型，并能回答一个最常被问倒的问题："你说的 ChatGPT，指的是公司、模型，还是那个网页？"

## 讲授

大部分混乱来自把五层东西叫成同一个名字。从下往上：

**第一层：厂商**——训练模型的公司。

| 厂商 | 模型系列 | 权重是否公开 |
|---|---|---|
| OpenAI | GPT 系列 | 否 |
| Anthropic | Claude 系列 | 否 |
| Google | Gemini 系列 | 否 |
| Meta | Llama 系列 | 是 |
| DeepSeek（深度求索） | DeepSeek 系列 | 是 |
| 阿里巴巴 | 通义千问 Qwen 系列 | 是 |
| 月之暗面 | Kimi | 部分 |
| 字节跳动 | 豆包 | 否 |
| 智谱 | GLM 系列 | 部分 |
| Mistral AI（法国） | Mistral 系列 | 部分 |
| xAI | Grok 系列 | 部分 |

**权重是否公开**这一列很实际：公开的（Llama、Qwen、DeepSeek）你可以下载下来在自己机器上跑，数据不出本机；不公开的只能通过 API 调用，数据必然要发出去。

**第二层：模型**——具体那个被训练出来的东西，有系列名和版本号。系列名稳定，版本号变得很快，所以本课只记系列，具体版本让 Agent 现场查。

**第三层：模型服务**——把模型变成你能调用的接口。同一个模型可以有好几条路：

- 厂商官方 API：`api.anthropic.com`、`api.openai.com`；
- 云平台转售：AWS Bedrock、Google Vertex AI、Azure OpenAI Service；
- 聚合/中转平台：一个 Key 调很多家；
- 本地运行：Ollama、LM Studio，只适用于权重公开的模型。

**第四层：应用**——普通人真正打交道的产品。ChatGPT 是 OpenAI 做的**应用**，底下跑的是 GPT 模型；Claude 的网页和桌面端是**应用**，底下是 Claude 模型。

**第五层：Agent**——能调用工具、自己跑循环、操作真实环境的程序。Claude Code、Cursor 属于这一层。它和第四层的区别是：应用主要在跟你说话，Agent 会真的去改你的文件、跑你的命令。

所以那个问题的答案是：**"我在用 ChatGPT" 说的是第四层的应用；"我在调 GPT-4o" 说的是第二层的模型；两句话不是一回事。**同理，"Claude 写的代码"通常指第五层的 Claude Code 干的活，模型只是它的一个零件。

常见误区：把应用名当模型名；以为换个应用就是换了模型（很多应用底下跑同一个模型）；以为本地跑的 Agent 就是本地推理（Claude Code 是本地程序，推理在云端）。

## 实验

1. 让 Agent 列出你这台机器上装的所有 AI 相关工具，逐个归类到五层里；
2. 打开当前 Agent 的配置，找出它实际用的是哪个厂商、哪个模型、经过哪个服务地址；
3. 让 Agent 查证一次**当前**各家的主力模型版本号，并注明查证日期——这是"会变的事实"的正确处理方式；
4. 挑一个权重公开的模型（如 Qwen 或 Llama），让 Agent 说明在本机跑它需要什么条件，不必真跑；
5. 开始写 `MY_AI_MAP.md`：第一节就是这五层，每层填上你自己实际在用的东西。

## 常见误区

- "国产模型"不是一个技术分类，权重是否公开、能不能私有部署才是有用的区分；
- 同一个应用可能同时接了好几家模型，用之前先看它切到了哪个；
- 版本号写进笔记时必须带日期，否则三个月后会误导你自己。

## 证据

`MY_AI_MAP.md` 第一节完成，五层各有学生自己的真实条目；学生能当场回答"你现在这句话是发给哪个厂商的哪个模型、经过哪个地址"。
