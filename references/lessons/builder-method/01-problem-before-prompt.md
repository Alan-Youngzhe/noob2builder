# 别从 Prompt 开始

## 目标

把“我要做一个 App”改写成一个具体用户在具体场景里遇到的问题。

## 讲授

Prompt 是给 Agent 的一段输入，不是产品起点。起点至少包含：谁遇到问题、什么时候发生、现在怎样解决、什么结果会更好。没有这些 Context，Agent 只能用常见模式替你猜，于是很容易生成登录、仪表盘、数据库等看起来完整但暂时无用的功能。

先区分四件事：

- **用户**：首先为哪个具体人做；
- **场景**：问题在什么动作前后发生；
- **问题**：目前损失的是时间、准确率、机会还是体验；
- **结果**：做完后用户能多完成什么。

## 实验

让学生用语音或自然语言讲最近一周反复出现的一件麻烦。Agent 负责整理，不立即推荐技术。输出：

```markdown
# PROJECT
用户：
发生场景：
现有做法：
最痛问题：
期望结果：
暂时不做：
```

## 证据

`PROJECT.md` 中没有“所有人”“提高效率”等无法验收的空话；如果使用这些词，必须补充具体行为和可观察结果。
