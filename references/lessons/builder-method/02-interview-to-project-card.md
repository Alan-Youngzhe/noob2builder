# 让 Agent 采访你

## 目标

让 Agent 补齐会改变实现方案的信息，同时避免无休止问卷。

## 讲授

好的采访不是“多问问题”，而是只追问会改变范围、数据、交付方式或风险的未知项。每轮最多问一个主题，已知信息不重复问。

优先顺序：

1. 最先使用的人是谁；
2. 输入从哪里来；
3. 期待什么输出；
4. 当前替代方案；
5. 哪些数据不能外发；
6. 第一版怎样交给别人；
7. 什么明确不做。

## 实验

要求 Agent 先复述已经确认的事实，再列出最多三个真正改变方案的问题。学生回答后，Agent 生成一页项目卡和“仍未确认”列表。学生逐条纠正，不允许 Agent 擅自把推测写成事实。

## 证据

- 一页项目卡；
- 至少一个非目标；
- 明确区分事实、假设和待确认项；
- 学生至少纠正一次 Agent 的复述或假设。
