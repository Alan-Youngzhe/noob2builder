# GrillMe 需求访谈与 PRD v0

## 目标

用 GrillMe 或同等访谈方法补齐真正改变需求的信息，产出一份薄的 PRD v0，同时避免无休止问卷。

## 讲授

好的采访不是“多问问题”，而是只追问会改变范围、数据、交付方式或风险的未知项。GrillMe 已安装时调用它；未安装时导师一次只问一个问题，并提供推荐答案供学生接受、修改或否决。已知信息不重复问，能从当前目录和资料确认的事实不盘问学生。

优先顺序：

1. 最先使用的人是谁；
2. 输入从哪里来；
3. 期待什么输出；
4. 当前替代方案；
5. 哪些数据不能外发；
6. 第一版怎样交给别人；
7. 什么明确不做。

访谈阶段只讨论用户意图、行为、输入输出、范围、成功标准、约束和边界；技术细节暂时交给后续 Agent 调查，不要求小白选择框架或数据库。

## 实验

要求 Agent 先复述已经确认的事实，再从第一个未解决的决策分支开始，一次问一个问题。访谈收敛后生成 `PRD.md` v0，至少包含：问题与用户、高层方案、目标、非目标、核心流程、行为级成功标准、约束、假设和开放问题。学生逐条纠正，不允许 Agent 擅自把推测写成事实。

## 证据

- 一页 PRD v0；
- 至少一个非目标；
- 明确区分事实、假设和待确认项；
- 学生至少纠正一次 Agent 的复述或假设。
