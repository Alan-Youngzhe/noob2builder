# Agent 在动哪个文件：目录、路径与扩展名

## 目标

学生能说出"当前目录"是哪里、绝对路径和相对路径的区别，能在 Agent 说"我改好了 config.json"时自己找到那个文件，并判断它是不是自己以为的那一个。

## 讲授

Agent 每次读写文件都发生在某个**当前工作目录**里。同一句"改一下 `data.csv`"，在不同目录下会命中不同的文件——这是小白最常见的困惑来源：明明改了，打开一看没变。

三个概念要分清：

- **绝对路径**从根开始，`/Users/你/Documents/项目/data.csv`，在任何地方都指向同一个文件；
- **相对路径**从当前目录开始，`data.csv`、`./data.csv`、`../data.csv` 含义完全不同；
- **扩展名**只是文件名的一部分，不改变内容。把 `.txt` 改成 `.json` 不会让里面的内容变成合法 JSON，只会让程序用错的方式去读它。

隐藏文件（以 `.` 开头，如 `.env`、`.gitignore`）在 Finder 和普通 `ls` 里默认看不见，但 Agent 能读能写。你以为"目录是空的"，它可能并不空。

常见误区：以为 Agent 和你看的是同一个目录；以为文件名相同就是同一个文件；以为改扩展名等于转换格式；以为看不见的文件不存在。

## 实验

在临时目录做完整一轮，每一步都要亲眼确认：

1. 让 Agent 打印当前工作目录（`pwd`），你在 Finder 里打开同一个位置对照；
2. 创建 `note.txt`，写入一行你能认出的内容，用 `ls -la` 看到它，同时看到有没有隐藏文件；
3. 在上一级目录再建一个同名 `note.txt`，内容不同；然后只用相对路径 `cat note.txt` 和 `cat ../note.txt`，说出哪一个是哪一个；
4. 把其中一个改名成 `note.json`，让 Agent 尝试按 JSON 解析它，观察报错；
5. 删除临时目录前，先用绝对路径确认一次你要删的到底是哪里。

## 常见误区

- `~` 是你的用户主目录，不是项目目录；
- 路径里有空格或中文时，命令里必须加引号；
- 同名文件在不同目录并存是常态，不是异常。

## 证据

学生能在不看提示的情况下，说出一个 Agent 刚操作过的文件的绝对路径，并解释它和自己刚才在编辑器里打开的那个是不是同一个。把第 3 步的两次输出记入存档。
