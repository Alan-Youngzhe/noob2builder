# 实现一个端到端切片

## 目标

让真实输入经过真实处理得到可见输出，并保留便宜纠错的版本历史。

## 开始前

需要 Git 时插入 Git 最小节点；涉及 Web 时读取 `../shared/web-product-foundations.md`；涉及秘密和外部服务时读取安全节点。

## 讲授

实现循环保持很小：读当前项目地图 → 实现一个步骤 → 运行最便宜验证 → 查看 diff → 保存 commit → 再进入下一步。一次让 Agent 重写整个项目会放大错误并让人无法判断变化。

## 实验

1. 创建或确认仓库和当前分支。
2. 把第一刀拆成 3–5 个可独立验证步骤。
3. 每次只让 Agent 做一个步骤，并要求说明改了哪些文件。
4. 查看 diff；学生确认意图没有漂移。
5. 执行对应测试或行为检查后提交。
6. 如果方案与项目卡冲突，停下来更新决策，不让 Agent静默改目标。

## 证据

可读 commit 历史、每步验证结果和一个从真实输入到真实输出的端到端切片。只启动开发服务器不算通过。
