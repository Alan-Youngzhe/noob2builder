# 网页是怎么来的：HTML 与 DOM

## 目标

学生能说清 HTML 是结构、浏览器把它解析成 DOM 树，页面"长什么样"先有结构才有后续一切；能在 DevTools 里找到任何一个页面元素对应的 HTML。

## 讲授

HTML 用标签描述"这里有什么"：标题、段落、按钮、输入框、列表。浏览器读 HTML 后生成 DOM——一棵可以被子查询和修改的元素树。JavaScript 改的是 DOM，不是 HTML 文件本身；这正是"页面会动"的根源。

语义化标签（`<header>`、`<main>`、`<button>` 而不是满屏 `<div>`）让 Agent、搜索引擎和读屏软件都能看懂结构。给 Agent 提需求时说"加一个按钮"不如说清"在卡片底部加一个提交按钮"，位置来自结构。

常见误区：把 HTML 当成"编程"；以为改浏览器里看到的东西会改源文件；分不清元素、属性和文本。

## 实验

在临时目录让 Agent 生成（或学生手写）一个单文件页面 `index.html`：一个标题、一段介绍、一个按钮、一个空列表。用浏览器打开，然后：

1. 打开 DevTools 的 Elements 面板，逐个找到这四个元素；
2. 在 Elements 里直接改标题文字，观察页面变化，再刷新，确认源文件没变；
3. 让学生在 DOM 树里指出 `<body>` 的第几个孩子是按钮。

## 证据

学生能在 DevTools 里完成一次"改了又恢复"的演示，并解释为什么刷新后修改消失。截图或录屏入档。
