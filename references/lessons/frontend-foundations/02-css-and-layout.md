# 样式与布局：CSS

## 目标

学生能区分"内容问题"和"样式问题"，理解盒模型与选择器，能用 DevTools 定位一个样式到底来自哪条规则，并做一次窄屏验证。

## 讲授

CSS 负责"看起来什么样"：颜色、字体、间距、布局。选择器决定规则作用于谁，盒模型（content → padding → border → margin）决定每个元素占多大地方。布局主要靠 Flexbox（一维排列）和 Grid（二维网格），浮动布局已经是历史。

样式会层叠和覆盖：同一个元素可能被多条规则命中，优先级和顺序决定谁赢。Agent 生成的样式经常"看起来对但不知道哪来的"，DevTools 的 Styles 面板能直接列出每条命中规则和来源文件行号——这是排查样式的第一工具。

常见误区：用 `<br>` 和空格排版；到处写 `!important`；只在宽屏看效果，移动端溢出不知道。

## 实验

沿用上一课的 `index.html`，让 Agent 加一个 `<style>` 块：卡片式布局、按钮悬停变色、内容最大宽度居中。然后：

1. 在 DevTools 里选中按钮，找到 hover 变色来自哪条规则；
2. 把窗口拖窄（或用设备模拟）到手机宽度，观察是否横向溢出，如有溢出让 Agent 修复并学生验证；
3. 学生在 Styles 面板里临时改掉一个颜色，确认页面即时变化。

## 证据

一张窄屏下无横向滚动的截图；学生能指着一个元素说出它的间距来自 padding 还是 margin。
