# Vue 与 React：同一功能写两遍

## 目标

学生见过两个主流框架的真实代码，能说清它们在写法上的核心差异，并为自己后续项目选定一个，理由是知情选择而不是"听说哪个火"。

## 讲授

React 用 JSX/TSX：UI 是 JavaScript 函数返回的标记，状态和逻辑都在函数里，`useState` 管状态。Vue 用单文件组件（SFC）：`<template>`、`<script>`、`<style>` 三段分置，`ref` 管状态，模板里用指令（`v-if`、`v-for`）写逻辑。

两者思想相同（声明式、组件化、数据驱动），差异在表达：React 更"一切是 JS"，Vue 更"模板与逻辑分区"。生态、招聘市场、AI 生成质量目前都不构成决定性差距。选定的实用标准：你的项目或团队已经在用哪个，就用哪个；都没有，各写一遍后凭手感选。

常见误区：同时在一个项目里混用两个框架；学了 API 差异但没认出背后是同一个思想；频繁换栈。

## 实验

1. 让 Agent 分别用 React（TSX）和 Vue（SFC）实现同一个"番茄钟卡片"：显示剩余时间、开始/暂停按钮、结束后变色；
2. 学生对照两份实现，填一张三行对照表：状态在哪声明、UI 在哪描述、事件怎么绑；
3. 学生宣布选定哪个作为本课程后续项目的框架，并用对照表说出理由。

## 证据

两份可运行实现、对照表、学生的选型理由。两个框架版本都必须真实跑起来过，不接受"代码看起来对"。
