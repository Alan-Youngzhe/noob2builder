# Git 是项目的时光机

## 目标

学生理解工作目录、仓库、变更、diff、commit 和历史，不背命令。

## 讲授

普通文件夹只保存“现在是什么样”；Git 仓库还记录一系列经过命名的变化。`diff` 回答“这次到底改了什么”，`commit` 回答“我决定保存哪组变化以及为什么”。GitHub 是放置仓库并围绕它协作的平台，不等于 Git 本身。

纠正常见误解：commit 不是自动备份全部电脑，也不是“项目完成才提交”。小而有意义的 commit 会降低 Agent 改错后的恢复成本。

## 实验

1. 让 Agent 在临时目录创建 `hello.txt`，不要使用学生的重要文件。
2. 初始化 Git 仓库并提交初始版本。
3. 修改一句话，查看 `git diff`。
4. 请学生用自然语言指出新增、删除或修改了什么。
5. 提交第二个版本并查看简短历史。

## 证据

- 临时仓库路径；
- 两条 commit；
- 学生对 diff 的解释。

实验结束后更新存档，不要求删除临时仓库；是否保留由学生决定。
