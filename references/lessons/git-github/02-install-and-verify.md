# 让 Agent 检查并安装 Git

## 目标

由 Agent 完成系统检查和安装，学生理解发生了什么并看到真实验证。

## 开始前

读取 `../shared/safety-and-secrets.md`。先运行 `git --version`；已经存在就不重复安装。

## 讲授

安装不是“命令没有报错”。完整链路是：检查系统与现状 → 说明将使用的官方或可信来源 → 学生确认可能的系统权限 → 执行 → 新终端或 PATH 生效 → 运行版本命令 → 在临时目录完成真实仓库实验。

## 实验

1. 检查操作系统、CPU 架构和已有 Git。
2. 如果缺失，让 Agent 给一个主方案和一个失败兜底；不要同时堆五种命令。
3. 需要管理员权限、图形安装或系统安全确认时，停下来解释并让学生亲自确认。
4. 安装后重新运行 `git --version`。
5. 创建临时目录，执行初始化、状态检查和第一次提交。

## 失败分流

- 命令不存在：检查是否需要新开终端和 PATH；
- 下载失败：区分 DNS、网络、镜像和服务不可用；
- 权限失败：不要反复使用更高权限盲试；
- 安装成功但 commit 失败：检查用户名和邮箱配置，不把身份配置问题误判为安装失败。

## 证据

保存版本输出和临时仓库的第一条 commit。仅看到安装器“完成”不算通过。
