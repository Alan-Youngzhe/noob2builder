# 改一次、看一次、回一次

## 目标

学生亲眼看见 Agent 的修改、只提交想要的内容，并安全恢复一次练习变更。

## 讲授

Agent 写代码后最重要的不是问“好了吗”，而是看 `git status` 和 diff。状态告诉你哪些文件改变；diff 告诉你内容怎样改变；commit 把一组确认过的变化变成可定位历史。

恢复有不同力度：丢弃未提交修改、反向撤销一个已提交变化、回到旧版本查看。不要向纯小白直接执行破坏性重置；先说明目标并只在临时仓库实验。

## 实验

1. 在练习仓库新增 `notes.md` 并修改 `hello.txt`。
2. 查看状态和 diff，让学生决定哪些变化属于同一次提交。
3. 分成两个有意义的 commit，而不是全部一次提交。
4. 故意改坏一句话，查看 diff 后恢复未提交变化。
5. 再制造一个错误 commit，用新的修复 commit 恢复正确结果。

## 证据

- 至少两个语义清楚的 commit；
- 一次未提交修改恢复；
- 学生能解释为什么修复 commit 比在真实协作仓库里重写历史更安全。
