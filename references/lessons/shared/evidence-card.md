# 共享节点：Builder 证据卡

证据卡不是证书，也不评价“天赋”。它让别人看见学生完成了什么、怎样验证以及还有什么未证明。

## 模板

```markdown
# Builder Evidence Card

作品：
解决的问题：
目标用户：

## 可获得的产物
- 作品地址或获取方式：
- 仓库或版本记录：

## 我亲自完成的关键判断
- 我否决或修改了 Agent 的什么：
- 为什么：

## 验收证据
- 主路径：
- 边界 / 失败路径：
- 实际运行的测试或命令：
- 一位真实用户的反馈：

## 一次失败与修复
- 怎样复现：
- 根因：
- 修改：
- 怎样确认没有复发：

## 未验证和剩余风险
-

隐私检查：不包含 Key、密码、私人数据和未授权内容。
```

## 规则

- 只记录实际发生的行为；模拟实验必须标明。
- 没有公开仓库也可以交付脱敏证据。
- Agent 可以整理文字，但学生必须确认每条事实。
- 证据卡完成后，学生自行决定是否把链接提交到 `WALL.md`。
