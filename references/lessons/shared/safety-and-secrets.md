# 共享节点：安全、秘密与可恢复操作

## 触发条件

第一次处理 API Key、账号、个人数据、外部服务、公开仓库、数据库写入、覆盖或删除命令时插入。

## 五条底线

1. API Key、密码、Cookie 和私有 token 不进入聊天截图、Git、证据卡或公开日志。
2. Agent 执行命令前先说明目标、影响范围、是否可恢复和验证方式。
3. 删除、覆盖、迁移、生产写入、付费调用和权限变更必须让学生亲自确认。
4. 优先在临时目录、测试数据、分支和预览环境实验；重要数据先备份并验证恢复方法。
5. 用户数据只收集当前任务需要的最少部分，明确来源、授权、保存和删除方式。

## API Key 实验

- 只确认变量是否存在和格式是否合理，不回显完整值；
- 使用环境变量或服务推荐的秘密管理方式；
- 创建 `.gitignore` 并在提交前检查 diff；
- 如果 Key 曾经进入公开位置，删除文本不够，必须立即轮换并检查历史。

## 完成检查

学生能回答：秘密存在哪里、谁能访问、怎样撤销；危险动作做错后怎样恢复；公开 PR 是否经过秘密扫描。
