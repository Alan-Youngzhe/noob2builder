# 共享节点：Web 产品基础

## 一张链路图

```text
用户动作
→ 前端组件与状态
→ Request / API
→ 后端规则
→ 数据库或外部服务
→ Response
→ Success / Empty / Error
```

前端是用户看见和操作的部分；后端负责不能只信浏览器的规则、秘密、权限和持久化；数据库保存共享状态。不是所有作品都需要后端或数据库。

## 界面状态

根据真实交互检查 Default、Hover、Focus、Active/Selected、Disabled、Loading、Empty、Success 和 Error。不是每个组件都要九种状态，但需要的状态不能缺失。Hover 只服务鼠标；键盘用户还需要 Focus。

## 小白必须分清

- 前端校验不等于后端安全；
- 登录不等于有权限访问所有数据；
- 页面显示成功不等于数据真的保存；
- localhost 只有本机可见，部署后才获得外部入口；
- Secret 不应打包进公开前端。

shadcn/ui 是可修改的组件源码参考，不是固定栈，也不会自动替项目补齐状态和测试。

## 实验

选择当前项目的一条真实流程，画出链路；启动页面后用鼠标和键盘操作，制造一次空数据、加载和失败，观察界面能否解释发生了什么以及如何恢复。
